# AIM RANGE / 准星训练场

PUBG-oriented browser aim-training prototype. Static website; no account or backend. Training records remain in each browser.

This demo is not affiliated with PUBG or Aim Lab. Port geometry, gun models and recoil parameters are illustrative and are not calibrated against PUBG.
